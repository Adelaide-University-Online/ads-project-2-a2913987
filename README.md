# Assessment 2.2: Project 2 - Degree Planning

A tool for ordering university courses according to their prerequisites.
## Project Structure

```
ADSAssignmentStarter/
├── src/
│   ├── main/
│   │   └── java/
│   │       ├── AbstractGraph.java          # Abstract class for graph
│   │       ├── AdjacencyListGraph.java     # Graph stored as adjacency lists
│   │       ├── Course.java                 # Course data model
│   │       ├── DegreeGraphBuilder.java     # Reads course file and build graph
│   │       ├── DegreePlanner.java          # Create study plan from prereqs
│   │       ├── Edge.java                   # Graph edges
│   │       ├── Graph.java                  # Graph interface
│   │       └── Runner.java                 # Main entry point
│   └── test/
│       └── java/
│           ├── AdjacencyListGraphTest.java
│           ├── CourseTest.java
│           ├── DegreeGraphBuilderTest.java
│           ├── DegreePlannerTest.java
│           └── EdgeTest.java
├── example_file_XBDA.txt                   # Example degree input file
├── .gitignore                              # Git ignore file
└── README.md                               # Project documentation
```
